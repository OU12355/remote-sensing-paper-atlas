# 国内论文导入

把 CNKI、万方或其他合法来源导出的题录文件放在本目录，更新任务会自动合并。支持：

- `.ris`
- `.bib` / `.bibtex`
- `.enw`（EndNote）

## 文件命名

程序优先根据文件名识别来源：

- `cnki-*.ris`、`知网-*.enw` 标记为 `CNKI`
- `wanfang-*.ris`、`万方-*.enw` 标记为 `万方`
- 其他文件名标记为 `手动导入`

示例：

```text
imports/
├── cnki-remote-sensing.ris
├── wanfang-change-detection.enw
└── lab-papers.bib
```

## 国内研究判定

只有在作者机构字段中明确出现 `CN`、`China`、`中国`，或明确的中文机构名称（大学、学院、研究院、研究所、科学院、测绘院、气象局等）时，论文才会标记为 `is_domestic: true`。

仅因为文件来自 CNKI/万方，或论文语言为中文，不会自动判定为国内研究。香港、澳门和台湾机构分别保留为 `HK`、`MO`、`TW`，不计入中国大陆口径。

## 版权要求

本目录只用于保存题录、摘要和链接等元数据。请只导入允许公开传播或已获得合法使用权限的数据，不要放入论文全文。数据库导出数据的使用还应遵守 CNKI、万方及所在机构的许可条款。
